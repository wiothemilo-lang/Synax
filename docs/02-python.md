# Domain code Python

## Dataset

`codeparrot/codeparrot-clean` — ~50GB Python code từ GitHub, đã dedupe và lọc sơ bộ,
có cột `license`, `content`, `repo_name`, `path`. Không gated, stream được.

| Thuộc tính | Giá trị |
|---|---|
| Tổng dung lượng | ~50GB text, ~5M file |
| License permissive | ~38% (Apache-2.0, MIT, BSD, ISC, Unlicense, CC0) |
| Nội dung dùng được | ~20GB, đủ ~6B token |
| Mục tiêu 60M | 4GB text ≈ 1B token |

## Chính sách giấy phép

Mặc định chỉ giữ các giấy phép permissive:

```
apache-2.0, mit, bsd-2-clause, bsd-3-clause, isc, unlicense, cc0-1.0, 0bsd
```

Loại bỏ GPL/AGPL/LGPL/MPL và `unknown`. Có thể mở rộng bằng `--licenses`, nhưng
hiểu rõ hệ quả pháp lý trước khi làm.

## Bộ lọc code

- `ast.parse` — chỉ giữ file Python hợp lệ (loại code Python 2 hỏng cú pháp).
- Độ dài 10–5.000 dòng, dòng tối đa 500 ký tự.
- Tỷ lệ chữ+số ≥ 0.25.
- Loại file auto-generated (`generated by`, `do not edit`, `@generated`).
- Dedupe exact SHA-256; tùy chọn MinHash cho near-duplicate.
- Chuẩn hoá CRLF → LF, bỏ null byte, bỏ trailing whitespace, **giữ nguyên indentation**.

## Lệnh

```bash
# 1. Tải + lọc + dedupe (stream, không cần tải cả 50GB)
python -m synax.data.code \
  --output data/clean/python.jsonl \
  --max-bytes 4000000000 \
  --progress-every 20000

# Chạy thử nhanh 200MB
python -m synax.data.code \
  --output data/clean/python-small.jsonl \
  --max-bytes 200000000

# 2. Tokenizer code 32k (giữ indentation)
python -m synax.data.tokenizer train \
  --input data/clean/python.jsonl \
  --output-prefix tokenizer/sp32-code \
  --vocab-size 32000 \
  --code \
  --tmp-dir data/tmp

# 3. Encode
python -m synax.data.tokenizer encode \
  --input data/clean/python.jsonl \
  --tokenizer tokenizer/sp32-code.model \
  --output data/tokenized/python-train.bin \
  --val-output data/tokenized/python-val.bin \
  --val-ratio 0.005 \
  --code

# 4. Train
python -m synax.train.pretrain --config configs/model-60m-code.yaml
```

## Tokenizer code

SentencePiece ở chế độ `--code` dùng:

- `remove_extra_whitespaces=False`
- `add_dummy_prefix=False`
- `allow_whitespace_only_pieces=True`
- `byte_fallback=True`

Nhờ vậy `decode(encode(code)) == code`, kể cả tab và thụt lề. Kiểm tra bằng test
`test_code_tokenizer_roundtrip`.

## Lưu ý

- Model 60M học được cú pháp Python cơ bản, không thay thế Copilot.
- Code sinh ra có thể giống code trong tập train; không dùng cho dự án cần
  đảm bảo không trùng lặp.
- Giữ metadata `repo`/`path`/`license` trong JSONL để truy vết nguồn.
